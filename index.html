CatHerdSIS
A lightweight Student Information System console for Moodle

Connect to your Moodle site

CatHerdSIS talks to Moodle's own Web Services REST API — the same API a real SIS integration would use. Nothing is proxied through a server of ours.

From a scoped external service — Site administration → Plugins → Web services → Manage tokens. Stored only in this browser, never sent anywhere but your Moodle site.
core_user_create_users core_course_update_courses enrol_manual_enrol_users + 12 more, scoped
⚠️ This console can only do what the token's service is scoped to allow — and only while that token is valid. Revoke it in Moodle at any time to switch this console off for everyone using it.
